STEP 1: Get Personal Access Token
───────────────────────────────────────────────────────────────
1. Go to: https://github.com/settings/tokens

2. Click: "Generate new token" → "Generate new token (classic)"

3. Settings:
   Name: Cursor AI Git Access
   Expiration: 90 days
   Scopes: ✓ repo (check this box)

4. Click: "Generate token"

5. COPY THE TOKEN! (starts with ghp_...) 
   You won't see it again!


STEP 2: Configure Git to Save Credentials
───────────────────────────────────────────────────────────────
Copy and paste these commands:

cd /Users/luisatrogu/Desktop/Test

git config credential.helper osxkeychain

git push -u origin main


STEP 3: Enter Credentials When Prompted
───────────────────────────────────────────────────────────────
Username: luisatrogu-sketch
Password: [Paste your token here - ghp_xxx...]


DONE! ✅

- No more manual authentication needed!
