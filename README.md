## 🎨 Design Specifications

This landing page has been meticulously crafted to match the original Figma design with exact:
- **Layout dimensions**: 1440×1024px
- **Colors**: 
  - Background: `#F6F3EF` (warm off-white)
  - Text Primary: `#000000` (black)
  - Accent: `#C76A47` (terracotta orange)
  - Shape Overlay: `#D2DCD3` (sage green)
  - Dark Element: `#2B2B2B` (charcoal)
- **Typography**:
  - Helvetica Neue for main content
  - Canela for contact information
- **Positioning**: All elements positioned exactly as per Figma coordinates

## 🚀 Getting Started

Simply open `index.html` in your browser:

```bash
open index.html
```

Or use a local server:

```bash
# Python 3
python -m http.server 8000

# Node.js (with http-server)
npx http-server
```

Then navigate to `http://localhost:8000`

## 📱 Responsive Design

- **Desktop**: 1440px and above (original design)
